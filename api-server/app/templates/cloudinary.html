Media Upload Service

Cloudinary Media Upload API

Upload images, videos, audio, PDFs, and common document files to Cloudinary using one API endpoint.

Endpoint

URL
POST /api/cloudinary/upload
Content type
multipart/form-data
Required field
file — the media or document file to upload
Maximum size
{{ max_upload_size_mb }} MB

Try it in the browser

Select a file and submit the form to see the response.

Local curl example

curl -X POST "http://localhost:8000/api/cloudinary/upload" \
  -F "file=@example.jpg"

Render curl example

curl -X POST "https://your-render-app.onrender.com/api/cloudinary/upload" \
  -F "file=@example.jpg"

Success response

{
  "success": true,
  "message": "File uploaded successfully",
  "data": {
    "secure_url": "https://res.cloudinary.com/example/image/upload/v123/example.jpg",
    "public_id": "example_public_id",
    "resource_type": "image",
    "format": "jpg",
    "bytes": 123456,
    "original_filename": "example",
    "asset_id": "abc123",
    "width": 1200,
    "height": 800
  }
}

Missing Cloudinary configuration

{
  "success": false,
  "message": "Cloudinary configuration is missing. Please set CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY, and CLOUDINARY_API_SECRET."
}

Environment setup

Create a local .env file or add these variables in the Render dashboard:

APP_NAME=API Server
APP_ENV=development
PORT=8000
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
MAX_UPLOAD_SIZE_MB=50

Secrets must stay in .env locally and in Render environment variables after deployment.
